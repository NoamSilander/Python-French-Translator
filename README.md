# *English To French Translator*
*(Technically any language translator, but I'm too lazy to add a dictionary with all the language options)*

The translator works by importing the `GoogleTranslator` class of the `deep-translator` library.

The translator asks you for an English word (or sentence now that I think about it), translates it via `GoogleTranslator` and prints the output.

## How to Run
1. Install the requirements: `python -m pip install -r requirements.txt`
2. Run `French_translator.py`
3. Pray it lets you through

## Notes
This is in no way a professional translator (if there is a standard), just a small project I made to learn Python.

Google might scream at you for reaching the limit, even though you haven't run anything. I don't know what causes that.
